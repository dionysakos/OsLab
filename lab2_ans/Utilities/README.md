# Utilities Library - utils.{c,h}

## Functions:

### 1. `check`
* **Operation:** Δέχεται το αποτέλεσμα μιας κλήσης συστήματος και ένα μήνυμα σφάλματος. Αν το αποτέλεσμα είναι `-1`, τυπώνει το σφάλμα μέσω της `perror()` και τερματίζει αμέσως τη διεργασία.

### 2.`safe_atoi`
* **Operation:** Μετατρέπει ένα string σε ακέραιο χρησιμοποιώντας τη `strtol()`. 
* **Safety:** Σε αντίθεση με την απλή `atoi()`, η `safe_atoi` ελέγχει αν ολόκληρο το string είναι έγκυρος αριθμός, επιστρέφοντας σφάλμα αντί για τυχαίες τιμές.

### 3. `safe_malloc`
* **Operation:** Εκτελεί τη `malloc()` και ελέγχει αυτόματα αν η δέσμευση απέτυχε (επιστροφή `NULL`). 
* **Safety:** Αν η μνήμη του συστήματος έχει εξαντληθεί, το πρόγραμμα τερματίζει με κατάλληλο μήνυμα σφάλματος αντί να προκαλέσει Segmentation Fault αργότερα.

### 4. `thread_i` struct (`typedef`)
Μια βοηθητική δομή δεδομένων που βοηθάει στο πέρασμα παραμέτρων στις συναρτήσεις που προορίζονται για τα νήματα κατά την δημιουργία τους.
* `tid`: Το αναγνωριστικό που αποδίδει η βιβλιοθήκη `pthread`.
* `thrid`: Το εσωτερικό ID που ορίζει η εφαρμογή (χρήσιμο για τον συγχρονισμό).
* `thrcnt`: Ο συνολικός αριθμός των νημάτων που τρέχουν.

> Οι safe_atoi, safe_malloc & το thread_i εμπνεύστηκαν και πάρθηκαν σαν ιδέα από τους δωσμένους κώδικες για τη πραγματοποίηση του δεύτερου εργαστηρίου.

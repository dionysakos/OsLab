# OS-LAB2 - Thread Synchronization

### 1. SimpleSync:
Το πρώτο μέρος εξετάζει την ασφαλή τροποποίηση κοινών δεδομένων από πολλαπλά νήματα.
* **Synchronization:**
    * **Mutexes:** Κλείδωμα σε επίπεδο λογισμικού για αμοιβαίο αποκλεισμό στην κρίσιμη περιοχή.
    * **GCC Atomic Operations:** Χρήση εντολών υλικού της CPU για αδιαίρετες πράξεις χωρίς κλειδώματα.

### 2. Mandelbrot Set:
Το δεύτερο μέρος αφορά την παραλληλοποίηση ενός υπολογιστικά απαιτητικού προβλήματος (Σύνολο Mandelbrot) με ανάγκη σειριοποίησης για το τύπωμα στην έξοδο.
* **Synchronization:**
    * **Semaphores:** Χρήση σηματοφόρων ~ token passing μεταξύ των νημάτων.
    * **Condition Variables:** Χρήση μεταβλητών συνθήκης για την ειδοποίηση του επόμενου νήματος στη σειρά.

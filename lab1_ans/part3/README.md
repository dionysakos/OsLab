# IPC (Μέρος 3)

## Code Analysis:

### 1.Signals
* **SIGCHLD**: Ο γονέας χρησιμοποιεί έναν handler για να παρακολουθεί ασύγχρονα πότε τερματίζουν τα παιδιά, ενημερώνοντας τη μεταβλητή `active_children` και αποθηκεύοντας τα exit codes.
* **SIGINT (Ctrl-C)**: Αν ο χρήστης πατήσει Ctrl-C, ο γονέας δεν τερματίζει, αλλά ενημερώνει τον χρήστη για το πόσα παιδιά εργάζονται εκείνη τη στιγμή. Τα παιδιά έχουν ρυθμιστεί να αγνοούν το `SIGINT` (`SIG_IGN`) για να ολοκληρώσουν την εργασία τους.
* **sigsuspend**: Χρησιμοποιείται για την αναμονή σημάτων με αποδοτικό τρόπο, αποφεύγοντας busy waiting και διασφαλίζοντας ότι ο γονέας "ξυπνάει" και ελέχγει **ατομικά** μόνο όταν συμβεί κάτι σημαντικό.

### 2.Pipe
Τα παιδιά γράφουν το τελικό τους αποτέλεσμα στο **άκρο εγγραφής** (`fd[1]`). Ο γονέας διαβάζει από το **άκρο ανάγνωσης** (`fd[0]`) και αθροίζει τα μερικά αποτελέσματα. Αυτό επιτρέπει την καταμέτρηση απεριόριστου αριθμού χαρακτήρων.

### 3.File Chunking
* Χρήση της `stat()` για την εύρεση του μεγέθους του αρχείου.

> Προτιμήσαμε αυτή, παρά την `fstat` που δουλεύει με περιγραφητές αρχείου καθώς δεν ανοίγει ο γονέας το αρχείο, οπότε γλυτώνουμε προγραμματιστικά 2 syscalls.

* Χρήση της `lseek()` από κάθε παιδί για να μετακινηθεί στην αρχή του δικού του offset.
* Μέριμνα για το τελευταίο παιδί ώστε να διαβάσει μέχρι το τέλος του αρχείου, καλύπτοντας τυχόν υπόλοιπα της διαίρεσης.

> Έτσι εξασφαλίσαμε **παράλληλη** εκτέλεση και αναζήτηση του χαρακτήρα, επιλέγοντας κάθε παιδί να ανοίγει το αρχείο ανάγνωσης/εισόδου.

## Assumptions:
* **Atomicity**: Οι μεταβλητές που χρησιμοποιούνται στους handlers και ενημερώνονται ασύγχρονα πρέπει να είναι δηλωμένες ως `volatile` για την αποφυγή  προβλημάτων βελτιστοποίησης από τον compiler, και `sig_atomic_t` για να ενημερώνονται ατομικά.
* **SA_RESTART**: Χρησιμοποιείται στη `sigaction` ώστε οι κλήσεις συστήματος (όπως η `read`) που διακόπτονται από σήματα να επανεκκινούνται αυτόματα.
* **Child Sleep**: Έχει προστεθεί η `sleep()` στα παιδιά για να μπορεί ο χρήστης να προλάβει να στείλει σήματα (Ctrl-C) και να δει την απόκριση του γονέα όσο οι εργασίες βρίσκονται σε εξέλιξη.

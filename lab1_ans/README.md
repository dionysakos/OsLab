# OS-LAB1

## Tasks:

### [Part 1] Handling Files
* Υλοποίηση του `charcnt` για σειριακή καταμέτρηση χαρακτήρων.

### [Part 2] Process Management
* Εξοικείωση με τη δημιουργία διεργασιών μέσω της `fork()`.
* Μελέτη του διαχωρισμού μνήμης και του συγχρονισμού γονέα-παιδιού με τη `wait()`.
* Χρήση της `execve()` για την εκτέλεση εξωτερικών προγραμμάτων.

### [Part 3] Signals & IPC
* Υλοποίηση παράλληλης καταμέτρησης με διαχωρισμό του αρχείου σε τμήματα (chunks).
* Επικοινωνία αποτελεσμάτων μέσω **Pipes**.
* Διαχείριση σημάτων (`SIGINT`, `SIGCHLD`) με χρήση των `sigaction` και `sigsuspend`.

### [Part 4] Distributed Computing (Frontend - Dispatcher - Workers)
* **Frontend:** Διεπαφή με τον χρήστη (interactive commands `+`, `-`, `i`, `q`).
* **Dispatcher:** Ο ενδιάμεσος που μοιράζει εργασία και παρέχει ανθεκτικότητα.
* **Workers:** Ανεξάρτητες διεργασίες που εκτελούν τον υπολογισμό.
